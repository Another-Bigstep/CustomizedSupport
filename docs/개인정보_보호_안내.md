# 개인정보 보호 안내 — 이 도구를 쓰기 전에 꼭 읽어 주세요

학생맞춤통합지원 업무는 성적·건강·가정형편 등 **민감한 개인정보**를 다룹니다.
이 저장소의 도구는 개인정보 보호를 최우선으로 다음과 같이 설계되었습니다.

## 1. 이 도구의 개인정보 처리 방식

- **웹앱(`app/index.html`)은 서버가 없습니다.** 입력한 모든 데이터는 사용 중인 컴퓨터의
  브라우저 저장소(localStorage)에만 남고, 네트워크로 전송되지 않습니다. 인터넷이 끊겨도 동작합니다.
- 통계 보고서에는 학생 이름·식별정보가 포함되지 않도록 집계 수치만 출력합니다.
- 화면의 「이름 가리기」를 켜면 목록·화면 표시에서 이름이 가림 처리됩니다(예: 김○수).

## 2. 사용자가 지켜야 할 것

| 상황 | 지킬 것 |
|---|---|
| PC 선택 | 공용 PC 사용 금지. 본인 업무용 PC + 로그인 계정 잠금 |
| 자리 비움 | 화면 잠금 (Win+L) |
| 백업 파일 | 백업(.json)·내보내기(.tsv) 파일에는 개인정보가 그대로 들어 있습니다. 암호화 드라이브·보안 폴더에 보관하고, 메신저·개인 메일로 전송하지 않기 |
| 인쇄물 | 계획서·회의록 등 출력물은 잠금 서랍 보관, 불필요 시 파쇄 |
| 기록 내용 | 사실 위주 최소한으로. 제3자(다른 학생·가족)의 정보는 이니셜 등으로 최소화 |
| 클라우드 | 학생 실명 데이터가 담긴 파일을 개인 클라우드·외부 AI 서비스에 올리지 않기 |
| 폐기 | 학년도 종료·전출 시 보존 기준에 따라 앱 데이터 삭제 + 백업 파일 삭제까지 확인 |

## 3. 동의와 법적 근거

- 개인정보 수집·이용, 민감정보 처리, 제3자 제공(외부기관 연계)은 각각 별도의 근거 또는 동의가 필요합니다.
- 「학생맞춤통합지원법」 및 같은 법 하위법령에 정보 처리 근거 조항이 있으므로, **어떤 처리에 동의가 필요한지는
  학교 개인정보 보호 담당자·교육청 지침으로 확인**하세요. 이 저장소의 동의서(`templates/01`)는 참고용 초안입니다.
- 웹앱은 학생별 「동의 확보 여부」를 기록하고, 미확인 사례를 대시보드에 표시해 누락을 막아 줍니다.

## 4. 이 도구가 하지 않는 것

- 나이스(NEIS)·교육청 시스템과 연동하지 않습니다. 공식 기록·보고는 공식 시스템에 하세요.
- 데이터를 외부로 전송·수집하지 않습니다. 따라서 분실 대비 백업도 사용자 책임입니다.
