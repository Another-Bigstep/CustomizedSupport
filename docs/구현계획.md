# 학생맞춤통합지원 관찰관리 앱 구현 계획 (초안)

교사가 일과 중 학생의 누가 관찰 기록을 빠르게 남기고, 나중에 분야별로 모아 보는 앱.
디자인은 별도로 제공받을 예정이므로 이 문서는 기능·데이터·개발 순서에 집중한다.

## 1. 먼저 확인이 필요한 사항

| 항목 | 질문 | 기본 가정 |
|---|---|---|
| 개인정보 | 학생 실명·학번을 앱에 저장하는가? 별칭/번호만 쓰는가? | 실명 저장. 단, 기기 밖으로 나가지 않도록 로컬 저장 |
| 저장 위치 | 기기 로컬(브라우저)만 쓸지, Google Sheets·Notion 동기화가 필요한지 | 1단계 로컬, 2단계 선택 동기화 |
| 사용자 | 교사 1인용인지, 담임·상담교사·보건교사가 함께 쓰는지 | 1인용 |
| 사용 기기 | 휴대폰 위주인지, PC 위주인지 | 휴대폰·PC 모두 (반응형) |
| 기록 대상 | 학급 전체인지, 지원 대상 학생 소수인지 | 학급 전체 명단 + 관심 학생 표시 |

## 2. 기술 구성 제안

- 빌드 도구 없는 정적 웹앱(HTML, CSS, JavaScript). 파일을 열거나 GitHub Pages에 올리면 바로 동작.
- 데이터는 브라우저 localStorage에 저장. 학생 정보가 외부 서버로 나가지 않는다.
- 내보내기 형식은 TSV(엑셀·시트 호환), Markdown(보고서·상담일지용), JSON(백업·복원).
- 2단계에서 Google Sheets 또는 Notion 동기화를 선택 기능으로 추가 가능.
- 휴대폰 홈 화면 추가(PWA)로 앱처럼 실행 가능하게 구성.

## 3. 기능 목록

### 1단계 (필수)

**학생 명단 관리**
- 학생 추가·수정·삭제 (학년, 반, 번호, 이름, 메모)
- 명단 일괄 붙여넣기 (한 줄에 한 명, 또는 시트에서 복사한 TSV)
- 관심 학생 표시(별표), 학급별 정렬, 이름 검색
- 학생 삭제 시 기록 보존 여부 선택

**관찰기록 작성 창**
- 학생을 누르면 바로 열리는 작성 화면. 날짜·시간은 현재 값으로 자동 입력
- 태그 선택(복수), 관찰 내용, 조치·후속 계획(선택), 장소·상황(선택)
- 작성 중 자동 임시 저장, 최근 사용 태그 우선 표시
- 같은 화면에서 이전 기록 확인 가능(누가 기록 타임라인)

**태그**
- 기본 태그: 복지, 상담, 건강, 학습, 문제행동, 기타
- 태그 추가·이름 변경·색상 지정·순서 변경
- 태그별 기록 수 표시

**기록 조회**
- 학생별 타임라인(최신순), 태그·기간 필터, 본문 검색
- 기록 수정·삭제, 수정 이력(작성일·수정일) 표시
- 전체 기록 보기(오늘 기록, 이번 주 기록)

**내보내기·백업**
- TSV: 학생·날짜·태그·내용·조치 열로 전체 또는 학생별 내보내기
- Markdown: 학생별 관찰 보고서(태그별 소제목, 날짜순)
- JSON 백업·복원 (기기 변경 대비)

### 2단계 (선택)

- 대시보드: 학생별·태그별 기록 수, 최근 30일 추이, 기록이 오래 없는 관심 학생 표시
- 후속 조치 관리: 기록마다 후속 조치 체크, 미완료 목록, 기한 알림
- 상담·연계 요청 초안: 특정 학생의 태그별 기록을 모아 상담 의뢰서·연계 요청 문안 생성
- Google Sheets·Notion 동기화(선택 활성화)
- 사진·파일 첨부(로컬 저장, 용량 제한)

### 3단계 (추후 검토)

- 여러 교사 공동 사용(계정·권한)
- 생기부 행동특성·상담일지 문안 초안 생성
- 학부모 상담 기록 연동

## 4. 데이터 모델

```
Student  { id, grade, class, number, name, memo, starred, createdAt }
Record   { id, studentId, date, time, tags[], content, action, place,
           followUpDone, createdAt, updatedAt }
Tag      { id, name, color, order }
Settings { schoolYear, defaultTags, exportFormat }
```

TSV 내보내기 열 순서:
`학년  반  번호  이름  날짜  시간  태그  관찰내용  조치  작성일시`

## 5. 화면 목록 (디자인 작업용)

1. 명단 화면: 검색창, 학급별 학생 목록, 관심 학생, 학생 추가·일괄 추가 버튼
2. 학생 상세 화면: 학생 정보, 빠른 기록 입력 폼, 태그 칩, 누가 기록 타임라인, 필터
3. 기록 작성·수정 모달: 날짜, 시간, 태그, 내용, 조치, 장소
4. 전체 기록 화면: 오늘·이번 주 기록, 태그 필터
5. 태그 관리 화면: 태그 목록, 색상, 순서
6. 설정·내보내기 화면: TSV, Markdown, JSON 백업·복원, 데이터 초기화
7. (2단계) 대시보드, 후속 조치 목록

휴대폰에서는 명단 → 상세가 한 화면씩 넘어가고, PC에서는 좌우 두 칸으로 배치한다.

## 6. 개발 순서

1. 데이터 저장소와 모델, 백업·복원
2. 학생 명단 관리
3. 기록 작성 창과 태그
4. 학생별 타임라인, 필터, 검색
5. TSV·Markdown 내보내기
6. 디자인 적용, 휴대폰 화면 정리, PWA
7. (2단계) 대시보드, 후속 조치, 외부 동기화
