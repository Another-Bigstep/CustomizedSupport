# 배포 안내

준비물: 학교 업무용 Google 계정, GitHub 저장소(이 저장소), 약 30분.

## 1. Google Sheet 만들기

1. 학교 업무 계정으로 Google Drive 에서 새 스프레드시트를 만듭니다. 이름 예: `관찰관리_2026`.
2. 이 시트는 **교사에게 공유하지 않습니다.** 앱을 통해서만 읽고 씁니다.
3. 계정에 2단계 인증을 켭니다.

## 2. Apps Script 넣기

1. 시트 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
2. 기본 `Code.gs` 내용을 모두 지우고, 이 저장소의 `backend/dist/Code.gs` 내용을 붙여넣습니다.
   (`backend/dist/Code.gs` 는 `js/lib.js` 와 `backend/Code.gs` 를 합친 파일입니다. 수정했다면 `npm run build:backend` 로 다시 만듭니다.)
3. 저장한 뒤 함수 목록에서 **setup** 을 선택하고 실행합니다. 권한 요청이 뜨면 허용합니다.
4. **실행 로그**를 열어 관리자 계정 이메일과 임시 비밀번호를 확인합니다. 시트에 `학생`, `관찰기록`, `태그`, `문장`, `교사`, `열람로그`, `로그`, `설정`, `회의` 탭이 생깁니다.

## 3. 웹 앱으로 배포

1. Apps Script 편집기 오른쪽 위 **배포 → 새 배포**.
2. 유형: **웹 앱**. 실행 사용자: **나**. 액세스 권한: **모든 사용자**.
   - 교사 로그인은 앱 안에서 이메일·비밀번호로 처리하므로 "모든 사용자"로 두어야 휴대폰에서도 접속됩니다.
3. 배포 후 나오는 `https://script.google.com/macros/s/…/exec` 주소를 복사합니다.
4. 브라우저에서 그 주소를 열어 `{"ok":true,...}` 가 보이면 정상입니다.

코드를 고친 뒤에는 **배포 → 배포 관리 → 편집 → 새 버전** 으로 다시 배포해야 반영됩니다.

## 4. 프론트엔드 설정과 GitHub Pages

1. `js/config.js` 의 `apiUrl` 에 3번의 주소를 넣고 `demo: false` 로 바꿉니다.
2. 커밋·푸시 후 GitHub 저장소 **Settings → Pages** 에서 배포 브랜치를 선택합니다(루트 폴더).
3. 몇 분 뒤 `https://<계정>.github.io/<저장소>/` 로 접속합니다.
4. 휴대폰에서는 브라우저 메뉴의 **홈 화면에 추가**로 앱처럼 씁니다.

## 5. 첫 설정 (관리자)

1. 관리자 계정으로 로그인하면 비밀번호 변경 화면이 먼저 나옵니다. 변경 후 PIN 도 등록합니다.
2. **설정 → 교사 명단 관리**에서 교사를 등록합니다. 역할과 담임반·수업반·전담 분야를 지정하면 임시 비밀번호가 표시됩니다. 본인에게 직접 전달하세요.
   - 담임반·수업반 표기: `기계과 3-2` 처럼 "과 학년-반".
3. **설정 → 학생 명단 관리**에서 명단을 붙여넣습니다. 한 줄에 `과 학년 반 번호 이름` (엑셀·시트에서 복사한 표도 그대로 됩니다).
4. **설정 → 분야·문장 관리**에서 분야 이름·색상과 자주 쓰는 문장을 학교에 맞게 고칩니다.

교사는 첫 로그인 때 비밀번호를 바꾸고, 잠긴 기록을 볼 역할(담임·전담)이면 설정에서 PIN 을 등록합니다.

## 6. 동시 저장 검증

교사 100명이 동시에 저장하는 상황을 미리 확인합니다.

```bash
node tools/stress.mjs "<웹앱 URL>" "<교사 이메일>" "<비밀번호>" "<학생 ID>" 30 2
```

같은 학생에게 30건을 동시에, 각 건을 3번씩 보내 **저장 30건 · 고유 ID 30개**가 나오면 됩니다.
학생 ID 는 시트 `학생` 탭 A열에서 복사합니다. 테스트 후 생긴 기록은 앱이나 시트에서 지웁니다.

Apps Script 는 동시 실행 수에 제한이 있어 일부 요청이 `BUSY` 로 돌아올 수 있습니다. 앱과 도구 모두
자동으로 재시도하며, 같은 ID 는 두 번 저장되지 않습니다. 실제 한도 값은 Google Apps Script 할당량 문서로 확인하세요.

## 7. 운영

- **학년도 전환**: 새 시트를 만들어 1~4단계를 반복하고 `apiUrl` 만 바꿉니다. 이전 시트는 보관합니다.
- **백업**: 시트 자체가 원본입니다. Drive 에서 주기적으로 사본을 만듭니다.
- **비밀번호 분실**: 관리자가 교사 명단에서 "비밀번호 초기화". PIN 은 본인이 설정에서 다시 등록합니다.
- **열람 감사**: `열람로그` 탭에 잠금 해제 성공·실패와 잠긴 기록 열람이 남습니다.
- **로그인 실패 5회**: 10분간 잠깁니다. PIN 도 동일합니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "서버에 연결할 수 없습니다" | `apiUrl` 이 `/exec` 로 끝나는지, 배포 액세스 권한이 "모든 사용자"인지 |
| "시트가 없습니다 (setup 을 실행하세요)" | Apps Script 에서 setup 실행 여부 |
| 로그인이 되지 않음 | 교사 탭 `사용` 열이 Y 인지, 이메일 대소문자 |
| 수정 시 "다른 사용자가 먼저 수정했습니다" | 정상 동작. 최신 내용을 확인한 뒤 다시 저장 |
