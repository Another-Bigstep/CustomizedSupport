# 학생맞춤통합지원 업무 흐름과 도구 활용 가이드

이 문서는 학교(단위학교 담당자) 관점에서 학생맞춤통합지원 업무 흐름을 정리하고,
각 단계에서 이 저장소의 어떤 도구를 쓰면 되는지 안내합니다.

## 0. 제도 개요 — 확인된 사실과 확인이 필요한 사항

**확인된 사실** (2026-09-02 웹 검색 기준):

- 「학생맞춤통합지원법」(법률 제20671호)이 **2025년 1월 21일 공포**되었고, **2026년 3월부터 학교 현장에서 전면 시행**되었습니다.
- 교육부는 17개 시·도교육청과 176개 교육지원청에 **학생맞춤통합지원센터**를 설치해 통합지원 체계를 구축하고 있습니다.
- 절차의 큰 틀: 모든 학교 구성원이 일상에서 학생을 관찰·발견 → **학생맞춤통합지원팀에 의뢰** → 통합 진단 → 맞춤 지원.
  가정 내 학대, 의료적 개입, 지역사회 돌봄 연계 등 학교의 노력만으로 어려운 경우
  **교육(지원)청(센터)에 심층 진단과 외부 지역자원 연계를 요청**할 수 있습니다.

**반드시 학교에서 확인해야 하는 사항** (이 저장소는 공식 지침이 아닙니다):

- 시행령·시행규칙과 소속 교육청의 운영 지침(팀 구성, 심의 절차, 공식 서식, 진단도구)
- 개인정보 처리의 법적 근거와 동의 요건 (학교 개인정보 보호 담당자와 협의)
- 관할 교육지원청 학생맞춤통합지원센터의 연락처와 의뢰 절차

```
        │

```

## 3. 긴급 사안은 별도 절차가 우선입니다

다음 사안은 통합지원 사례관리와 **별개로, 즉시** 해당 절차를 진행합니다.

- **자살·자해 위험**: 관리자·전문상담(교)사 보고, 보호자 연락, 위기 대응 절차 (자살예방 상담전화 **109**)
- **아동학대 의심**: 교직원은 신고의무자 — 지체 없이 **112** 신고
- **학교폭력 사안**: 학교폭력 사안처리 절차 진행 (신고·상담 **117**)

웹앱 체크리스트에서 해당 문항을 체크하면 같은 안내가 자동 표시됩니다.

## 4. 업무를 가볍게 만드는 사용 습관

1. **기록은 그때그때 1분씩**: 상담 직후 웹앱에 2~3줄 기록 + 다음 조치 예정일 입력 → 대시보드가 일정 관리를 대신합니다.
2. **주간 루틴**: 주 1회 대시보드에서 「지연된 조치」와 「30일 이상 기록 없음」만 훑어보면 사례가 방치되지 않습니다.
3. **협의회 전**: 「사례 요약 인쇄」로 학생별 경과를 출력하면 협의 자료 준비가 끝납니다.
4. **보고 시즌**: 「통계·보고」에서 기간을 지정해 실적 보고서(마크다운·TSV)를 자동 생성합니다. 보고서에는 학생 이름이 들어가지 않습니다.
5. **백업 습관**: 금요일마다 「데이터 백업」 버튼 → 백업 파일은 안전한 저장소에 보관합니다.
