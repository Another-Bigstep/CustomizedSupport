# 학생맞춤통합지원 관찰관리

교사가 일과 중 학생의 누가 관찰 기록을 빠르게 남기고, 분야별로 모아 보는 앱입니다.
휴대폰·PC 모두에서 쓰는 반응형 웹앱이며, 데이터는 학교 계정의 Google Sheets에 저장됩니다.

## 구성

```
index.html, css/, js/      정적 웹앱 (GitHub Pages 또는 아무 웹 서버)
js/lib.js                  브라우저·서버가 함께 쓰는 공용 로직 (권한, 잠금, 알림, 내보내기)
js/mock.js                 데모 모드 가상 서버 (배포 전 미리보기용)
backend/Code.gs            Google Apps Script 백엔드 (시트 접근, 잠금, 인증)
backend/dist/Code.gs       lib + Code 를 합친 붙여넣기용 파일 (npm run build:backend)
tests/                     단위 테스트, 브라우저 스모크 테스트
tools/stress.mjs           동시 저장 부하 테스트
docs/                      구현 계획, 배포 안내
```

## 주요 기능

- **학생 명단**: 과 → 학년 → 반 탐색, 이름 검색, 내 담당 학급 바로가기. 명단 편집은 관리자만.
- **빠른 기록**: 분야(복지·상담·건강·학습·문제행동·진로·기타) 선택, 자주 쓰는 문장, 공개 범위 선택.
- **기록별 공개 범위**: 작성자가 "교사 전체" 또는 "담당 교사만"을 고릅니다. 담당 교사만 기록은
  해당 학생의 담임, 작성자, 상담·복지·보건 전담 계정만 PIN 6자리로 해제해 읽을 수 있습니다.
  해제·열람은 열람로그 시트에 자동 기록됩니다.
- **홈**: 오늘 기록, 2주 미기록, 잠금 기록, 위기 알림(문제행동 3주 연속, 장기 미기록).
- **학생 상세**: 누적·최근 30일·주요 분야, 분야별 필터, 누가 기록 타임라인.
- **기록 목록·통계**: 기간·분야·작성자 검색, 분야별 분포, TSV·Markdown 내보내기.
- **통합지원 회의**: 안건 학생 선정과 학생별 기록 요약, 회의록, 결정 사항(담당·기한·완료) 추적,
  회의 자료 Markdown 내보내기. 회의 내용은 작성자·전담·행정담당자·안건 학생의 담임만 봅니다.
- **동시 사용 안전**: 기록은 추가만(덮어쓰기 없음), UUID 로 중복 방지, 서버 잠금, 수정은 버전 검사,
  전송 실패 시 브라우저 보관함에서 자동 재전송.

## 바로 실행 (데모 모드)

`js/config.js` 의 `apiUrl` 이 비어 있으면 브라우저 안의 가상 데이터로 동작합니다.

```bash
npm start          # http://localhost:8765
```

로그인 화면의 데모 계정 버튼을 누르면 됩니다. 데모 PIN 은 `123456` 입니다.
모든 학생·교사 이름은 가상의 예시입니다.

## 실제 배포

`docs/배포안내.md` 를 따라 Google Sheet 와 Apps Script 를 준비한 뒤 `js/config.js` 의 `apiUrl` 에
웹앱 URL 을 넣고 GitHub Pages 에 올립니다.

## 테스트

```bash
npm test                       # 공용 로직 단위 테스트
npm run test:e2e               # Chromium 스모크 테스트 (npm start 실행 후, playwright 필요)
node tools/stress.mjs <API_URL> <이메일> <비밀번호> <학생ID> 30   # 배포 후 동시 저장 검증
```

## 개인정보

복지·상담·건강·문제행동 기록은 민감한 개인정보입니다. 시트는 학교 업무 계정이 소유하고 교사에게는
시트 링크를 공유하지 않습니다. 앱은 HTTPS 로만 접속하고, 공용 PC 에서는 "전체 잠금(앱 종료)"으로 로그아웃하세요.
배포 전 학교 개인정보 보호 지침과 맞는지 담당자 확인을 권장합니다.
