# 학생맞춤통합지원 업무 도우미 (CustomizedSupport)

학교 현장의 **학생맞춤통합지원** 담당자를 위한 업무 경감 도구 모음입니다.
발굴 → 진단·파악 → 계획 수립 → 지원 실행 → 모니터링 → 종결로 이어지는 사례관리 흐름을
설치 없이, 개인정보를 외부로 보내지 않고 한곳에서 처리할 수 있게 합니다.

> ⚠️ 이 저장소는 교육부·교육청 공식 도구가 아닙니다. 공식 지침·서식·시스템(나이스 등)이 항상 우선하며,
> 서식과 체크리스트는 학교 실정에 맞게 수정해 쓰는 **참고용 초안**입니다.

## 구성

| 경로 | 내용 |
|---|---|
| `app/index.html` | **사례관리 웹앱** — 브라우저로 열기만 하면 되는 단일 파일. 대시보드, 학생 사례, 발굴 체크리스트, 협의회 회의록, 자원 연계 목록, 실적 통계, 백업까지 지원 |
| `templates/` | 의뢰서·동의서·계획서·회의록·일지·연계의뢰서·종결보고서·가정통신문 등 마크다운 서식 8종 |
| `data/` | 위기징후 체크리스트, 지원자원 목록(TSV, 엑셀에서 편집 가능), 가상 예시 데이터 |
| `docs/` | 업무 흐름 가이드, 개인정보 보호 안내 |
| `scripts/make_report.py` | 웹앱에서 내보낸 TSV로 기간별 실적 보고서를 만드는 파이썬 스크립트 (선택 사항) |

## 빠른 시작 (웹앱)

1. 이 저장소를 내려받아(Code → Download ZIP) 압축을 풉니다.
2. `app/index.html` 파일을 더블클릭해 브라우저(크롬·엣지·웨일)로 엽니다. 설치·인터넷 불필요.
3. 「데이터·설정」에서 학교명·담당자명을 입력합니다.
4. 처음이라면 대시보드의 **「가상 예시 데이터로 둘러보기」**로 기능을 살펴본 뒤,
   「데이터·설정 → 모든 데이터 삭제」 후 실제 사용을 시작하세요.

### 웹앱이 덜어 주는 일

- **일정 챙기기**: 기록마다 「다음 조치 예정일」을 넣으면 대시보드가 지연·임박 조치를 자동 정리
- **방치 예방**: 30일 이상 기록이 없는 사례, 개인정보 동의 미확인 사례를 자동 표시
- **문서 작성**: 지원계획서·사례 요약·협의회 회의록·체크리스트 결과지를 입력 데이터로 자동 생성(인쇄)
- **실적 보고**: 기간을 지정하면 개인정보 없는 통계 보고서(마크다운·TSV)를 자동 집계
- **데이터 이동**: JSON 백업·복원, 엑셀 호환 TSV 내보내기

## 개인정보 보호

- 웹앱은 **서버 없이** 동작하며 데이터는 사용 중인 PC의 브라우저에만 저장됩니다.
- 반드시 [`docs/개인정보_보호_안내.md`](docs/개인정보_보호_안내.md)를 읽고 사용하세요.
  (공용 PC 금지, 백업 파일 보안 보관, 기록 최소화 등)
- 브라우저 데이터를 지우면 기록도 사라집니다. 상단 「데이터 백업」 버튼으로 주기적으로 백업하세요.

## 통계 스크립트 (선택)

웹앱 없이 TSV 파일만으로 보고서를 만들 수도 있습니다.

```bash
python3 scripts/make_report.py \
  --students data/예시/학생사례_예시.tsv \
  --logs data/예시/지원기록_예시.tsv \
  --from 2026-03-01 --to 2026-09-02 \
  --school "예시고등학교" -o 실적보고서.md
```
